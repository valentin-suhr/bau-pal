# Contributing

This is currently a portfolio and research prototype. Small, evidence-preserving
improvements are welcome.

1. Create a focused branch.
2. Keep official facts, interpretations and estimates in separate fields.
3. Add source locators and review status for new planning evidence.
4. Run `npm run lint` and `npm test` before opening a pull request.
5. Describe any data assumptions or geographic limitations in the pull request.

Do not commit credentials, unrestricted bulk source downloads, local databases
or generated files above GitHub's file-size limit.
